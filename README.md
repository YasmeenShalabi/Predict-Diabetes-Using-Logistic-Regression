<h1>Diabetes Prediction Using Logistic Regression</h1>

This project uses the Pima Indians Diabetes Dataset to build a machine learning model that predicts whether a person is diabetic based on health measurements. The model is trained using Logistic Regression, a common algorithm for binary classification.

**What the Project Does**

Loads the Pima Indians Diabetes dataset from an online source

Splits the data into training and testing sets

Trains a Logistic Regression model

Evaluates performance using:

    Accuracy
    
    Confusion Matrix
    
    Classification Report

Visualizes the confusion matrix using Seaborn

Predicts diabetes for a new sample input

**Features Used**

The model uses the following health-related features:

Pregnancies

Glucose

BloodPressure

SkinThickness

Insulin

BMI

DiabetesPedigreeFunction

Age
